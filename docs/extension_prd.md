# Product Requirements Document (PRD) - Locator-X Chrome Extension

## 1. Executive Summary & Objective

**Locator-X** is an advanced browser extension designed for QA engineers, test automation developers, and software development engineers in test (SDETs). The core objective is to accelerate the creation, validation, and maintenance of web test automation scripts. 

Instead of manual selector inspection via generic browser inspector tools, Locator-X automates the discovery, extraction, and generation of highly robust, unique, and maintainable locator strategies (ID, Name, CSS, XPath, Axes XPath) across major automation frameworks (Selenium, Playwright, Cypress) while taking into account dynamic content, shadow roots, and iframe encapsulation.

---

## 2. Target Audience & User Personas

### Persona A: The QA Automation Engineer (Selenium/Playwright User)
*   **Need:** Quickly write script elements, generate unique relative XPaths that won't break when CSS styles or minor layouts change, and easily organize locators into Page Object Models (POM).
*   **Pain Point:** Dynamic IDs (auto-generated by frameworks like Ember, React, Angular) break tests constantly. sandboxed iframes and Shadow DOMs are difficult to inspect and traverse.

### Persona B: The Manual Tester transitioning to Automation
*   **Need:** Learn how to formulate robust XPath and CSS patterns. Needs feedback on whether their manual selector is unique and what element it targets on the page.
*   **Pain Point:** Syntax errors in XPath, lack of understanding of complex XPath axes relationships (e.g., following-sibling, ancestor).

## 3. Scope of Features

### 3.1. Selector Generation & Smart Identification (Home)
*   **Core Inspection:** User can click the "Inspect" button, hover over any web element, and see its metadata in real-time. Clicking the element locks it and generates a suite of locators.
*   **Supported Selectors:** ID, Name, Tagname, ClassName, CSS Selector, LinkText, Partial LinkText, Relative XPath, and Absolute XPath.
*   **Smart ID Filtering:** Automatically avoid selecting auto-generated/dynamic IDs (e.g., alphanumeric hashes, timestamps, or framework-specific prefixes like `ctl00`, `ember`).
*   **Smart Correction:** If a selector is slightly wrong or matching multiple nodes, provide smart corrections or suggestions to make it unique.
*   **Interactive Search & Validation:** A search box that evaluates manual or generated selectors in real-time. If it matches exactly one element, show its full tag info. If it matches multiple, allow cyclic navigation (Next/Prev) to highlight each matching element on the page.

### 3.2. Page Object Model (POM) Manager
*   **Page Management:** Create, rename, delete virtual "Pages" (representing application screens) to group elements.
*   **POM Elements Registry:** Save generated or customized locators to specific pages.
*   **Preferred Strategy Configuration:** Select which locator strategy to default to per element class, and dynamically configure horizontal table structures to group or select alternate selectors.
*   **Actionable Export/Import:** Copy POM pages or export the entire stored configuration to migrate between instances.

### 3.3. Relative XPath Axes Generator (Axes)
*   **Context:** Sometimes elements have no unique attributes. The user wants to locate a target element relative to a nearby unique "Anchor" element.
*   **Process:**
    1.  Inspect and click the **Anchor** element.
    2.  Inspect and click the **Target** element.
    3.  The system identifies the relationship axis (preceding-sibling, following-sibling, preceding, following, descendant, ancestor) and outputs a unique, validated relative XPath selector.
*   **Swap Feature:** Quickly swap the anchor and target assignments to recalculate the axis direction.

### 3.4. Multi-Locator Scanner (MultiScan)
*   **Code Parsing:** Drag and drop or copy-paste code files into the utility to find existing test locators.
*   **Framework Recognition:** Extract selectors using regex mappings for:
    *   Selenium (Java, Python, JS)
    *   Playwright (JS, Python, Java)
    *   Cypress
*   **Registry Analysis:** Display all matched locators in a clean table for validation.

### 3.5. Dom Freezing (Debugger Mode)
*   **Context:** Hover menus, tooltips, and dynamic popups disappear as soon as you click the extension panel to inspect.
*   **Action:** Trigger a countdown timer. When the timer hits zero, trigger a JavaScript debugger pause (`debugger;`) to freeze the DOM state, allowing transient elements to be easily inspected.

## 4. Business & Usage Tier Limits

Locator-X implements features based on subscription plans (e.g. Free, Pro, Enterprise):
*   **Saved Locators Cap:** Enforce max count for saved selectors.
*   **History Storage Cap:** Automatically splice older activity log items based on limits.
*   **Feature Availability Check:** Restrict features like Axes Generator, Smart Correction, Debugger Freeze, or Dark Theme to premium plan holders.
